# Tap Tunes 拍拍樂

A tiny offline-capable web app for toddlers: tap anywhere on the screen and each tap plays the next note of
*Twinkle Twinkle Little Star*, *Row Row Row Your Boat* or *Baby Shark*. VoiceOver-friendly for parents.

Single `index.html` (HTML + CSS + JS, no dependencies). Play it: https://julianzhumin.github.io/toddler-music/
